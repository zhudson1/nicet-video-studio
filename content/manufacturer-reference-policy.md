# Manufacturer Reference and Visual Accuracy Policy

## Rule
Never invent or relabel a manufacturer's model. When naming a model, use its official manufacturer photo and model-specific installation instructions to validate the illustration. If geometry or terminal legends cannot be verified, use a clearly labeled generic conceptual model instead. No invented wiring diagrams.

## Verified NOTIFIER examples
- **FCM-1:** Addressable supervised control module for notification or control circuits, requiring external power for connected loads. Manufacturer installation instructions: https://prod-edam.honeywell.com/content/dam/honeywell-edam/hbt/en-us/documents/manuals-and-guides/installation-guides/hbt-fire-fcm-1-installation-instructions.pdf
- **FRM-1:** Addressable relay module with dry-contact outputs for auxiliary equipment. Manufacturer product data sheet: https://buildings.honeywell.com/content/dam/hbtbt/en/documents/downloads/hon-ba-5-fcm1-frm1-sa.pdf
- **FCM-1-REL:** Releasing control module for specific listed applications, NOT interchangeable with a generic FCM-1. Manufacturer instructions: https://prod-edam.honeywell.com/content/dam/honeywell-edam/hbt/en-us/documents/manuals-and-guides/installation-guides/notifier-us/ba-fire-I56-2992.pdf

**Important correction:** An FCM-1 and FRM-1 should not be presented as interchangeable. A dry-contact relay demonstration should identify FRM-1 (or remain generic), while a supervised output example should identify FCM-1, subject to exact listed applications.

## Code interpretation
NFPA 72 editions vary by jurisdiction and adoption. Verify the edition and amendments applicable to the project before citing requirements. NFPA's overview: https://www.nfpa.org/news-blogs-and-articles/blogs/2016/12/19/nfpa-1-referencing-nfpa-72-and-fire-alarm-requirements-in-nfpa-1

## Production quality gates
1. Identify exact brand, model, revision and manufacturer document.
2. Cross-check physical form factor, terminals, LEDs, and labeling with official references.
3. Validate all stated electrical functions, supervision and power-source assumptions.
4. Label conceptual signal-flow graphics as illustrative, not field wiring.
5. Obtain human technical review before public release.
6. Do not publish if any brand-specific element remains unverified.
